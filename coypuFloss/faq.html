1. About the project

What is Coypu, in one sentence?

A live-coding sequencer for Pharo: you write patterns as expressions, it plays them continuously, and you keep editing while they run.

Does Coypu make sound?

No. It decides when and what; a backend decides how it sounds. Choosing one is most of Setup.

Which Pharo versions work?

Pharo 11, 12 and 13.

Why the name?

A tribute to Kyma's Capytalk dialect — the coypu being a rodent closely related to the capybara. Coypu was originally written to drive Kyma over OSC.

How is it related to Phausto?

Coypu sequences; Phausto synthesises. Coypu's baseline pulls Phausto in as a dependency, so installing one gives you both — see Setup §3.2.

Is it like TidalCycles?

The string notation is openly inspired by it, and both can drive SuperDirt. See §7 for where they differ.

2. Installing

What is the install line?

Metacello new
  baseline: 'Coypu';
  repository: 'github://lucretiomsp/coypu:master';
  load.

Metacello cannot find it

The branch is master. Phausto's is main — mixing them up is the usual cause.

What comes with it?

Ducasse's OSC package and Phausto. MIDI does not — that needs Pharo-Sound separately. See Setup §3.2.

Do I need SuperCollider?

Only for the SuperDirt backend. Phausto runs inside your image with no external software, though it does need its native libraries in place.

Is there a ready-made image?

Yes — Pharo Launcher 3.4.4 offers a Pharo Music image with Coypu and Phausto already installed. See Pharo Music Image.

3. Why is there no sound?

By far the most common question. In order:

CheckFix
Is a Performer set?p performer: PerformerSuperDirt new — without one, Coypu sends nowhere and reports nothing
Is the transport running?p play
Is the backend up?SuperDirt.start in SuperCollider; an activeDSP: for Phausto
Does the instrument name exist?Try #bd; check SuperDirt listOfSamples
Does the pattern have triggers?16 rests is silent by design

One part is silent, the others play

Almost always the instrument key — a misspelt sample folder or a missing synth.

Sound continues after stop

A second transport, or a note-off that never arrived. p muteAll then p stop.

4. Rhythms

How many are there?

Thirty-one, all documented with verified step patterns in the Rhythm Library. Rhythm list gives the same list in the image.

Why does my rhythm sound cut off?

Its length does not divide the number you gave it. trueAksak is 13 steps and the jungle patterns are 32 — use a multiple of the pattern's own length.

16 bomba: '36 38' raises an error

A source bug — bomba: never assigns its pattern. Plain 16 bomba works; add notes with notes:.

Why do adowa and sikyi sound the same?

They carry an identical pattern in the current source.

Can I add my own?

Yes — an Integer extension with the <rhythmCreation> pragma. See Community §4.2.

Is #(5 16) euclidean the bossa clave?

No. Coypu uses a Bresenham variant that yields a rotation of it. Use 16 bossa. #(3 8) does give tresillo exactly, and #(6 16) gives bembé.

5. Writing patterns

What does the number before a rhythm mean?

Steps, not triggers. 8 quavers is eight steps containing four triggers.

Why does my melody rotate each cycle?

You gave it fewer notes than the pattern has triggers, so the note list wraps. It is usually a feature — match the counts if you want it fixed.

My melody is an octave out

asMidiNote treats c4 as 60; the older asMidiNN treats it as 72.

How do I layer two patterns on one sound?

Join them with ,, or use two instrument keys pointing at the same sound. One key holds one Sequencer.

What is the difference between the string notations?

The asDirt… family is step-based; Mondo is cycle-based and supports subdivision and per-cycle alternation. See Rhythms: Advanced §4.

My Mondo alternation never changes

Alternations advance per cycle, so they need playCyclicFor: rather than play.

6. Playing live

Do I have to stop to change something?

No. Re-evaluate the line and it changes at the next step. That is the whole point.

unmute: brought back everything

It ignores its argument and restores the whole snapshot. Re-send the one part you want instead — see Performing §4.1.

How do I change tempo smoothly?

The transport re-reads the tempo every step, so repeated small freq: changes from a forked loop give a ramp.

Can I sync hardware to Coypu?

Yes — PerformerMIDI emits MIDI clock and a start message. Set your hardware to external sync.

Is there an undo?

One snapshot slot: temporarySave and restore. There is no stack, and every mute or solo overwrites it.

What is the biggest single gesture?

p rhythm: 16 tresillo — every part in the Performance onto the same rhythm at once.

7. How it compares

Compared withDifference
TidalCyclesBoth are pattern languages driving SuperDirt. Tidal is Haskell and purely cycle-based; Coypu is Smalltalk and primarily step-based, with cycles available through Mondo. Coypu also drives Kyma, MIDI and in-image DSP.
SuperCollider aloneCoypu is a sequencer, not a synthesis language. It is a layer above, and SuperDirt is one of several things it can drive.
A DAWNo timeline, no arrangement view, no undo history. What you get instead is that the whole arrangement is text you can regenerate, and that it changes without stopping.
PhaustoIts sibling: Phausto builds instruments, Coypu plays them. Many sessions use both.

Why Smalltalk for this?

Because the image is live. There is no edit–compile–run cycle to interrupt the music, the whole system is inspectable while it plays, and a pattern is an ordinary object you can examine mid-performance.
