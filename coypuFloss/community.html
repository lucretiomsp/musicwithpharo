1. The project

Coypu is written by Domenico Cipriani, who performs and publishes as Lucretio. It has been public since January 2021 and was originally built to drive SymbolicSound Kyma over OSC.

1.1 The wider family

Beyond Pharo, Coypu sits in the live-coding tradition alongside TidalCycles, which its string notation is modelled on, and can drive SuperDirt, the sampler most of that community uses.

2. Where to ask

QuestionBest place
Something in Coypu is brokenCoypu issues
A DSP or synthesis questionPhausto issues, or its community page
A general Pharo questionPharo Discord or Pharo Discourse
A SuperDirt or SuperCollider questionThe SuperCollider forum and the TidalCycles community
An error on this pageThe edit link at the foot of it
Work out which layer first A silent pattern can be Coypu not sending, or the backend not receiving. Switching to PerformerSuperDirt and trying 16 downbeats to: #bd is the quickest way to find out which half is at fault.

3. Reporting a problem

Coypu is maintained by one person. A report that reproduces in thirty seconds is far more likely to be fixed than one that needs a conversation first.

IncludeBecause
A minimal snippetThe shortest pattern that shows the problem, ready to paste
Pharo version11, 12 and 13 are all supported and can differ
Which PerformerMost behaviour is backend-specific
How Coypu was installedMetacello from which commit, or the Pharo Music image
Expected versus actualSilence, an exception and the wrong sound are three different bugs
Check the known quirks first Several surprising behaviours are already documented in Changelog §3 — unmute: restoring everything, squiz: setting the reverb, bomba: raising. If yours is on that list, it is known.

4. Contributing

4.1 To this manual

Every page has an Edit this page on GitHub link at the foot, which opens the source directly in GitHub's editor. A typo fix is a two-minute pull request.

Corrections — a selector that does not exist, a pattern that does not match the source, a snippet that no longer runs.
Ethnomusicology — the Rhythm Library notes are curated by hand. Corrections from people who play these traditions are especially welcome.
Troubleshooting entries — if something confused you it will confuse the next person. Symptom-first phrasing, one or two sentences.
Gallery patterns — short, runnable, verified against the current package.
Two files are generated rhythm-library.html comes from _tools/generate-rhythm-library.cjs, and navigation from coypu-nav.js. Editing either page by hand will be overwritten — change the generator or the nav array instead.

4.2 Adding a rhythm

A new rhythm is an Integer extension carrying the <rhythmCreation> pragma, which is what puts it in Rhythm list and in this manual: 

"Integer >> myRhythm"
" a one-line comment describing the rhythm and its origin"

<rhythmCreation>
<onTheFlyEssentials>
| pattern |
pattern := #( 1 0 0 1 0 1 0 0 ).

^ ((0 to: self - 1) collect: [ :i |
     pattern at: (i rem: pattern size) + 1 ]) asRhythm asSeq

Then rerun the generator and the rhythm appears with its pattern, onsets and grouping computed automatically. Add an entry to NOTES in the generator for the prose, and to REGIONS for where it belongs — the generator warns about any rhythm not placed in a region.

Say where it comes from The most valuable part of a rhythm contribution is not the array — it is knowing which tradition it belongs to, what it is called there, and what it is for. That is the part nobody can derive from the source.

5. Credit where it is due

Coypu's rhythm library is a collection of other people's music. The patterns come from living traditions with their own names, functions and practitioners, and the library is a pointer to them rather than a substitute.

Whose workWhat it gave us
Afro-Cuban, Puerto Rican, Haitian and Brazilian musiciansThe clave family and its relatives — the majority of the library
Ashanti, Ewe, Yoruba and Congolese traditionsThe bell timelines those patterns descend from
Balkan and Anatolian musiciansThe additive metres
Godfried ToussaintThe Euclidean analysis, and the 16-pulse bembé adaptation Coypu implements
The TidalCycles communityThe mini-notation tradition Mondo follows
SymbolicSoundKyma and Capytalk, which Coypu was first written for and named after
The Pharo communityThe live image that makes editing while it plays possible

If you use Coypu in a performance, a release or a paper, crediting Coypu is appreciated — and hearing about it more so.

7. Troubleshooting

Is my problem Coypu or the backend?

Try a known-good pattern on SuperDirt — §2.

My issue has had no reply

The project is maintained by one person alongside other work. A minimal reproducible snippet is the single biggest thing that speeds up a response — §3.

I found a mistake in this manual

Use the edit link at the foot of the page — §4.1.

I edited rhythm-library.html and my change vanished

It is generated. Change the generator — §4.1.

I know one of these rhythms is misdescribed

Please say so. The patterns are verified against source, but the prose about origins is curated and is exactly where an error would hide — §4.1.

Can I use Coypu commercially?

The repository carries no licence file at present. Ask the author before assuming either way.
